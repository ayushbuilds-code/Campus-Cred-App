# 5-minute demo script

Setup: `npm run quickstart`, open http://localhost:4000 on a laptop; open the same address on a phone (same Wi-Fi, use the laptop's IP) or a second browser window.

| Time | Do this | Say this |
|---|---|---|
| 0:00 | Login screen | "Four clubs, ten members each. Every record has proof behind it." Tap **Coding President**. |
| 0:30 | Home, then **Club Days** | "Plans are due a week ahead, the advisor approves, members are announced three days before." Show a pending and a changes-requested plan. |
| 1:15 | Open today's Coding activity, **Start check-in** | Full-screen QR + code. "It changes every 20 seconds, so a forwarded screenshot is useless." |
| 1:45 | Phone, sign in as **MSOT26025**, Check in now, enter the code | Count goes 0 to 1 on the laptop. Try the same code again: "already checked in". |
| 2:30 | Back on the laptop, **Mark present** for someone, give a reason | "Corrections need a reason and are logged." Open Admin, Audit log later. |
| 3:00 | Phone: submit a link. Laptop: **Score**, **Publish scores** | "Participation certificate issued automatically." |
| 3:30 | Phone: Certificates, download. Private window: open its verify link | "Anyone can verify it, no login." Upload an edited PDF: rejected. |
| 4:15 | Admin: Dashboard, Reports | Participation by club, inactive clubs, zero-participation students, monthly CSV. |
| 4:45 | Transcript | "The student owns a verified record. The JSON version feeds the Placement Copilot." |
